# Unit Testing

## Description
A project with unit test examples to demonstrate Java unit testing skills.

## Tech Stack
- Java
- JUnit 5
- Mockito
- JaCoCo (code coverage)

## What was done
- 5 standard unit tests
- 1 parameterized test
- Mockito used for creating mock objects
- JaCoCo report generated to check test coverage

## How to run tests
mvn clean test

# Unit-тестирование

## Описание
Проект с примерами unit-тестов для демонстрации навыков модульного тестирования на Java.

## Стек технологий
- Java
- JUnit 5
- Mockito
- JaCoCo (проверка покрытия кода)

## Что сделано
- 5 обычных unit-тестов
- 1 параметризованный тест
- Подключена библиотека Mockito для создания мок-объектов
- Сгенерирован отчёт JaCoCo с проверкой покрытия кода

## Как запустить тесты
mvn clean test
